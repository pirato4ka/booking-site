# Сайт студии «Адам и Ева»

Статический информационный лендинг студии красоты и эстетики тела.
Сам сайт остаётся статическим: услуги, цены и контакты он читает из
`assets/data/site.json`, который публикует веб-панель `python -m app.web`.
Если файла нет, работает встроенный в `main.js` прайс.

## Структура

```text
site/
├── index.html              # разметка, SEO и JSON-LD
├── manifest.webmanifest    # добавление на домашний экран
├── robots.txt
├── README.md
└── assets/
    ├── css/styles.css      # все стили и адаптив
    ├── js/main.js          # прайс, фильтры, меню, анимации
    ├── data/site.json      # опубликованный контент из админки
    └── img/
        ├── hero.svg        # обложка
        ├── favicon.svg
        ├── icon-192.png
        ├── icon-512.png
        ├── icon-maskable-512.png
        └── apple-touch-icon.png
```

## Локальный просмотр

Из корня проекта:

```powershell
python -m http.server 8000 --directory site
```

Откройте `http://localhost:8000/`.

Можно открыть `site/index.html` и напрямую, но локальный сервер ближе к
реальному хостингу.

## Админ-панель и правка контента

Панель живёт на том же домене, что и сайт, и не требует отдельного фронтенда:

```powershell
python -m app.web
```

- сайт — `http://127.0.0.1:8080/`
- панель — `http://127.0.0.1:8080/admin/`
- логин и пароль — `ADMIN_PANEL_USER` и `ADMIN_PANEL_PASSWORD` в `.env`

В панели можно менять услуги и цены, направления, телефон, адрес, часы работы,
ссылки на мессенджеры и тексты главной. Каждое сохранение пишет данные в SQLite
и сразу публикует их в `site/assets/data/site.json`; кнопка «Опубликовать сейчас»
пересобирает файл вручную.

Важно:

- панель — это Python-процесс, поэтому на чисто статическом хостинге она не
  заработает. Запускайте её на VPS рядом с ботом или локально и загружайте
  обновлённый `site/assets/data/site.json` на хостинг;
- для боевого домена ставьте HTTPS и `ADMIN_COOKIE_SECURE=true`;
- смените пароль и `ADMIN_PANEL_SECRET` из `.env.example` перед публикацией.


## Устройства и адаптивность

Вёрстка не имеет фиксированной ширины: один и тот же HTML работает на телефонах,
планшетах, ноутбуках, больших мониторах и ТВ, в портретной и горизонтальной
ориентации, на складных устройствах и при сильном увеличении.

| Ширина экрана | Что меняется |
| --- | --- |
| до 340 px | скрыты декоративные подписи обложки, минимальные отступы |
| 341–400 px | компактные отступы и кегль, карточки в одну колонку |
| 401–520 px | один столбец, кнопки на всю ширину, короткая шапка |
| 521–760 px | один столбец, бургер-меню во всю ширину |
| 761–1024 px | сетки в 2 колонки, бургер-меню панелью 380 px |
| 1025–1439 px | полная навигация в шапке, 3 колонки в прайсе |
| 1440–1799 px | контейнер 1240 px |
| 1800–2199 px | контейнер 1360 px, крупнее типографика и отступы |
| от 2200 px | контейнер 1480 px, масштаб под 4K и ТВ |

Дополнительно учтено:

- `viewport-fit=cover` и `env(safe-area-inset-*)` — вырезы, скругления и
  домашние индикаторы не перекрывают контент;
- `100dvh` для меню и оверлеев — корректно при скрывающихся панелях браузера;
- горизонтальная ориентация с низкой высотой (`max-height: 560px`) — компактная
  шапка, обложка и отступы, меню прокручивается;
- `pointer: coarse` — цели нажатия не меньше 44 px, поля ввода 16 px (iOS не
  зумит страницу при фокусе);
- `hover: none` — отключены «залипшие» hover-эффекты на сенсорных экранах;
- `prefers-reduced-motion`, `prefers-contrast: more`,
  `prefers-reduced-transparency`, `forced-colors: active` — поддержаны;
- `@media print` — прайс печатается в две колонки, карточки не разрезаются;
- без JavaScript меню раскрыто статически, а вместо прайса показывается телефон.

`manifest.webmanifest` и иконки 192/512 px позволяют добавить сайт на домашний
экран Android/iOS и открывать его без адресной строки. Хостинг должен отдавать
манифест с типом `application/manifest+json` (Python 3.11+ и большинство
статических хостингов делают это по умолчанию).

Проверено в headless Edge с эмуляцией устройств на ширинах 280, 320, 390, 430,
667, 768, 834, 844, 1024, 1025, 1120, 1121, 1280, 1440, 1800, 1920 и 2560 px,
включая горизонтальную ориентацию: горизонтального переполнения нет, меню
помещается в экран, все 60 услуг рендерятся.

## Публикация

Загрузите **содержимое** папки `site/` на любой статический хостинг
(nginx, GitHub Pages, Cloudflare Pages, Netlify, VPS). Сборка не нужна.
Корневой файл — `index.html`.

После публикации:

1. Укажите домен в `<link rel="canonical">`, если он нужен.
2. Проверьте, что `robots.txt` доступен по адресу `/robots.txt`.
3. При желании добавьте `og:image` с растровой обложкой 1200 × 630 px.
4. Настройте HTTPS на хостинге.

## Что менять без панели

Если панель недоступна, остаются ручные правки:

- контакты и тексты — в `index.html`; но при наличии `assets/data/site.json`
  сайт берёт значения из него;
- прайс — в массиве `SERVICES` в `assets/js/main.js` (резервный вариант, пока
  JSON не опубликован);
- каталог бота — в `app/db/seed.py` (`CATALOG`).

Чтобы ручные изменения в базе попали на сайт, запустите панель и нажмите
«Опубликовать сейчас» — или выполните публикацию из Python:

```python
from app.db import SessionLocal
from app.services import site_data

async with SessionLocal() as session:
    await site_data.export_payload(session)
```

### Формат site.json

```json
{
  "version": 1,
  "generated_at": "2026-10-25T17:20:00+03:00",
  "settings": {"phone": "+7 (988) 668-65-24", "phone_raw": "+79886686524"},
  "categories": [{"slug": "plasma", "title": "Холодная плазма", "short": "Холодная плазма"}],
  "services": [{"category": "plasma", "title": "Омоложение лица", "price": 10000, "mode": "fixed", "duration": 60, "featured": 1}]
}
```

`mode`: `fixed`, `from`, `custom`. `featured` — место в «Популярном» (0 — не
показывать). Сайт сортирует популярные карточки по этому числу.


### Фотография

Сейчас обложка — локальная SVG-композиция, чтобы сайт работал без внешних
запросов и не зависел от стоковых изображений. Чтобы поставить фото студии:

1. Положите файл в `site/assets/img/` (лучше WebP, около 1200 × 1400 px).
2. Замените `src` и `alt` у изображения в блоке `hero__arch` в `index.html`.
3. При необходимости поправьте `object-position` в `.hero__arch img`.

## Чего здесь нет

- Форм и сбора персональных данных.
- Онлайн-записи и личного кабинета.
- Внешних шрифтов, CDN и аналитических скриптов.
- Встроенной карты: ссылка на Яндекс.Карты открывается отдельно.

Поэтому cookie-баннер и политика обработки данных для форм не нужны.
Хостинг может вести собственные access-логи — это регулируется на его стороне.

## Важно

Цены на сайте не являются публичной офертой. Перед процедурой мастер
уточняет противопоказания и подходящий протокол. Информация на сайте не
заменяет консультацию специалиста.
